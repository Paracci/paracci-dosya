# Katkı

Katkılar AGPL-3.0-only proje lisansı kapsamında değerlendirilir. Katkı yaptığınız içeriği paylaşma hakkınız olmalıdır. Başka tarafların hak/lisans bildirimlerini koruyun.

- Gerçek dava belgesi, kişi bilgisi, dosya adı, UYAP tokenı, oturum/çerez, özel yol veya ekran görüntüsü göndermeyin. Geri döndürülemeyen paylaşım yerine sentetik örnekle yeniden üretin.
- Hata raporunda sürüm, Windows/Chrome sürümü, işlem adımları ve belgesiz hata metni yeterlidir. JSON raporu/logu olduğu gibi eklemeyin.
- Kaynak örnekleri sentetik olmalıdır; gerçek dosyayı yeniden adlandırmak veya yalnızca kişinin adını kapatmak yeterli anonimleştirme değildir.
- Değişikliğe uygun Node/Python testlerini ve `npm run check`, `npm run public:check` çalıştırın. SKIP/NOT RUN sonuçlarını PASS diye raporlamayın.
- Portal origin/token/kök kontrolünü, tek sınırlı yeniden denemeyi veya kullanıcı yetkisi sınırını gevşetmeyin. Genel komut çalıştırma, ağ dinleyicisi veya habersiz belge yükleme eklemeyin.

Güvenlik bildirimleri için [SECURITY.md](SECURITY.md). Bu proje bir hukuki yardım kanalı değildir.
